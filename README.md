Лёгкий Выпуск
Лёгкий Выпуск — приложение для автоматизации работы релиз-менеджера. Оно собирает данные из разных сервисов, объединяет их в одном месте и даёт участникам релиза обсуждать и согласовывать выпуск прямо внутри приложения.

Как будет работать приложение

1. Сбор данных из разных сервисов. Лёгкий Выпуск подключается к сервисам, которые используются при подготовке релиза: трекеру задач, системе сборки, системе тестирования, инструментам проверки безопасности и мониторингу. Данные подтягиваются автоматически. Если сервис подключить нельзя, данные можно загрузить файлом.

2. Агрегация в одном месте. Все данные о релизе собираются в единую карточку. В ней видно, какие задачи входят в релиз, прошли ли сборка и тесты, есть ли открытые ошибки и уязвимости. Релиз-менеджеру больше не нужно переходить между сервисами и сводить информацию вручную.

3. Работа участников релиза внутри приложения. Каждый участник релиза — разработчики, тестировщики, безопасность, эксплуатация, владелец продукта — видит карточку и оставляет комментарии к своей части. Здесь же он отмечает, готов ли его участок, или указывает, что нужно исправить.

4. Доработка и повторная проверка. Если есть замечания, после исправлений данные обновляются, а участники видят изменения и проверяют их снова. Вся история обсуждения сохраняется в карточке.

5. Готовность к выпуску. Когда все участники подтвердили готовность, релиз-менеджер видит, что релиз можно выпускать. Решение и все комментарии остаются в истории.
